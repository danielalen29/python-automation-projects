# Python Automation Projects
A collection of Python automation projects built while developing practical freelancing skills.

## Projects

### 1. CSV Cleaner
Cleans contact CSV files by validating required fields and standardizing values into a consistent format
(e.g. daniel -> Daniel).

Skills:
- pathlib
- File handling
- Dictionaries
- csv module
- Functions and module imports

### 2. Safe File Mover
Moves .jpg, .pdf and .txt files into separate folders based on their file type.

Skills:
- pathlib
- File automation
- Dictionaries
- Functions and module imports

### 3. Extension Counter
Counts files in a folder by their file extension.

Skills:
- pathlib
- File automation
- Dictionaries
- Loops

### 4. Invoice Processor
Sorts invoices, receipts and other files into separate folders based on their filename prefixes.

Skills:
- pathlib
- File Automation
- Dictionaries
- Nested loops
- Functions and module imports

### 5. Excel Report
Creates a formatted Excel sales report with required fields, formulas, filters, and currency formatting.

Skills:
- pathlib
- openpyxl
- File handling
- Dictionaries
- Loops
- Functions and module imports

### 6. Pandas Sales
#### Business Data Cleaner
Cleans a messy CSV sales file, handles invalid or missing values, creates summaries, 
and exports the results to Excel.

Skills:
- pathlib
- openpyxl
- pandas
- Data Cleaning
- Missing-value handling
- Functions and module imports

#### Multiple Sales Cleaner
Reads multiple CSV files, combines them into one dataset, preserves the source filename, 
and exports the combined data as a new CSV file.

Skills:
- pathlib
- pandas
- CSV processing
- DataFrame concatenation
- Functions and module imports

#### Sales Report
Reads sales data from a CSV file, cleans and summarizes the data, and exports a formatted Excel sales report.

Skills:
- pathlib
- openpyxl
- pandas
- Data cleaning
- Data aggregation
- Functions and module imports

### 7. GitHub API Report
Retrieves repository data for a GitHub user, cleans and organizes the information,
and exports the results to both CSV and Excel.

The report includes:
- Repository name
- Programming Language
- Star count
- Repository URL

Skills:
- Requests
- GitHub API
- csv
- openpyxl
- API data handling
- Data aggregation
- Excel reporting
- Functions and module imports
